# Matriz de contradicciones y diferencias documentales

## Criterio

Una diferencia entre una norma de la Carta y una mención de acta no significa por
si sola que exista una modificación. Se clasifica como `CONTRADICCION_TEXTUAL`
cuando ambos textos regulan el mismo asunto con contenidos incompatibles;
`DIFERENCIA_DE_ALCANCE` cuando el acta parece referirse a un caso, evento o
periodo concreto; `NO_CONTRADICCION` cuando los textos pueden coexistir; y
`PENDIENTE_CONFIRMACION` cuando falta el acta completa, su aprobación, alcance o
vigencia.

## Secuencia cronologica de posibles cambios

- La Carta contiene las reglas base de aseos, ruido, cargos y quejas.
- 07/04/2023: aparece una mención sobre bicicletas/neveras y tres multas, sin
  texto suficiente para confirmar una norma.
- 12/10/2023: aparecen propuestas y consensos sobre lavandería/terraza y nueva
  organización de aseos; el alcance temporal no está determinado.
- 08/11/2023: se discuten horarios y multas de ruido, pero el registro conserva
  propuestas y conteos sin una resolución normativa completa.
- 28/08/2024 y 19/09/2024: aparecen decisiones sobre terraza, cargos y casos
  individuales; no hay texto de modificación de la Carta.
- 10/10/2024: se aprueba un régimen particular para el caso 220.
- 18/02/2025: se aprueba el plan piloto de cocina y se rechaza el esquema 3/2/1
  propuesto por nuevos residentes.
- 21/08/2025: se registra una medida para representante de aseo con cantidades
  incompatibles dentro del mismo tema.
- 16/06/2026 y 20/08/2026: se anuncian borrador/modificación de Carta y nuevos
  cargos, pero no se aporta la Carta modificada ni su aprobación final.

Una decisión posterior solo se convierte en modificación cuando existe texto
aprobado, alcance general, fecha de vigencia y relación explícita con la norma.
