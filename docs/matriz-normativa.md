# Matriz normativa de la Carta Interna

Fuente exclusiva de esta matriz: `Carta Interna 2do Piso RGSB.pdf`. Los estados
no declaran vigencia jurídica externa; indican cómo puede tratarse documentalmente
la regla dentro del proyecto. `NO_VERIFICADO` se usa cuando el fragmento requiere
confirmación visual o institucional.

## Límites de interpretación

La Carta no contiene, de forma completa, un catálogo de categorías como “visitas”,
“habitaciones”, “cocina” o “medidas correctivas” separado de sus secciones. Esas
categorías son etiquetas de organización propuestas para el sistema, no nuevas
normas.
